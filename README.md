# UndertaleModTool on the Web

This is a port of [UndertaleModTool](https://github.com/UnderminersTeam/UndertaleModTool) (the popular modding, decompiling and unpacking tool for GameMaker games) running in a web browser through the power of [WebAssembly](https://webassembly.org)!

The GUI is rebuilt from scratch using web technologies, many features are not available yet.

## Contributing

If you found a bug, first try checking if it can be reproduced on the main Windows version of UndertaleModTool. If the bug exists there as well, then report it to their [issues page](https://github.com/UnderminersTeam/UndertaleModTool/issues) instead.

For feature requests or bugs about the web version, report it on the [issues page](https://github.com/ngyikp/UndertaleModTool-Web/issues).

For more details on contributions and the project's AI policy (tl;dr: no), see the [CONTRIBUTING](https://github.com/ngyikp/UndertaleModTool-Web/blob/main/CONTRIBUTING.md) file.
